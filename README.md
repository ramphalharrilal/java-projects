# Java Projects

A collection of Java applications developed while building hands on programming skills through my Computer Science studies. These projects demonstrate object oriented programming, graphical user interfaces, collections, data analysis, functional programming, and input validation.

## Project Directory

| Project                                                              | Description                                                                      | Key Concepts                                                 |
| -------------------------------------------------------------------- | -------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| [Student Management GUI](student-management-gui)                     | Desktop application for student records, course enrollment, and grade management | Java Swing, event handling, `JTable`, `ArrayList`, `HashMap` |
| [Course Enrollment System](course-enrollment-system)                 | Manages students, courses, capacity limits, enrollment, and grades               | OOP, collections, object relationships, validation           |
| [Employee Stream Analysis](employee-stream-analysis)                 | Analyzes a fictional employee dataset using modern Java stream operations        | Stream API, lambdas, functional interfaces, filtering        |
| [Library System](library-system)                                     | Manages book inventory, borrowing, and returns                                   | `HashMap`, classes, methods, input validation                |
| [Vehicle Information System](vehicle-information-system)             | Creates and displays cars, motorcycles, and trucks                               | Interfaces, encapsulation, multiple classes                  |
| [Student Record Management System](student-record-management-system) | Adds, updates, searches, and displays student records                            | OOP, `ArrayList`, static methods, validation                 |
| [Stock Price Analysis](stock-price-analysis)                         | Calculates averages, maximum values, occurrences, and cumulative sums            | Arrays, `ArrayList`, method overloading, data processing     |
| [Quiz Game](quiz-game)                                               | Interactive console quiz with score calculation and user feedback                | Conditionals, loops, user input, program flow                |

## Skills Demonstrated

* Java syntax and programming fundamentals
* Object oriented programming and encapsulation
* Classes, interfaces, constructors, and methods
* Arrays, `ArrayList`, and `HashMap`
* Java Swing and event driven programming
* Stream API and lambda expressions
* Input validation and exception handling
* Data processing and analysis
* Technical documentation with project specific READMEs

Each project folder contains the Java source code, documentation, and an application preview where applicable.
