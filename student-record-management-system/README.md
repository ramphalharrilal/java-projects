# Student Record Management System

A console based Java application for adding, updating, searching, and displaying student records.

## Features

* Add students using a name, ID, age, and grade
* Prevent duplicate student IDs
* Update existing student information
* Search for a student by ID
* Display all stored student records
* Track the total number of students
* Validate menu choices and age entries
* Continue running until the user chooses to exit

## Java Concepts Demonstrated

* Object oriented programming and encapsulation
* Classes, constructors, and methods
* `ArrayList` collections
* Static fields and methods
* Loops, conditional statements, and switch cases
* User input with `Scanner`
* Input validation and error handling

## Running the Program

```bash
javac StudentRecordManagementSystem.java
java StudentRecordManagementSystem
```

The application stores records in memory, so the information resets when the program closes.
