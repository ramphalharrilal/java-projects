# Vehicle Information System

A console based Java application for creating and displaying information about cars, motorcycles, and trucks.

## Features

* Create car records with make, model, year, number of doors, and fuel type
* Create motorcycle records with make, model, year, number of wheels, and motorcycle type
* Create truck records with make, model, year, cargo capacity, and transmission type
* Display formatted details for each vehicle
* Validate whole number and decimal entries
* Reject zero and negative numeric values
* Continue running until the user chooses to exit

## Java Concepts Demonstrated

* Interfaces and interface implementation
* Object oriented programming
* Encapsulation with private fields
* Constructors, getters, and setters
* Multiple classes in one application
* Vehicle specific behavior and attributes
* Loops, conditional statements, and switch cases
* User input with `Scanner`
* Input validation and error handling

## Running the Program

```bash
javac VehicleInformationSystem.java
java VehicleInformationSystem
```
