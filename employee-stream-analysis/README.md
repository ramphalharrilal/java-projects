# Employee Stream Analysis

A Java application that analyzes a fictional employee dataset using the Stream API, lambda expressions, and functional programming techniques.

## Features

* Store employee names, ages, departments, and salaries
* Transform employee objects into formatted name and department strings
* Calculate the average employee salary
* Filter employees above an age threshold
* Identify employees earning more than the average salary
* Collect processed results into new lists
* Display the original and analyzed datasets

## Java Concepts Demonstrated

* Java Stream API
* Lambda expressions
* The `Function` functional interface
* Method references
* `map`, `mapToDouble`, `filter`, `average`, and `collect`
* `Collectors.toList()`
* `List` and `ArrayList`
* Object oriented programming and encapsulation
* Data transformation and filtering

## Running the Program

```bash
javac EmployeeStreamAnalysis.java
java EmployeeStreamAnalysis
```

All employee records in this portfolio version are fictional sample data.
